# Weekly Meal Planning

## Purpose

Plan a week of meals in one session to reduce daily decision fatigue and avoid unnecessary shopping trips.

## Steps

1. **Review what's already in the kitchen** — check fridge, freezer, and pantry. Note anything that needs using up this week.
2. **Pick a theme or constraint** — e.g. "use up the lentils", "no more than 30 mins per meal", "batch cook Sunday".
3. **Draft 5–7 dinners** — don't plan every meal; lunches and breakfasts can be leftovers or simple defaults.
4. **Check for ingredient overlap** — look for meals that share ingredients (e.g. both use cabbage) to reduce waste.
5. **Write the shopping list** — go through each meal and list only what's missing. Group by section (produce, dairy, dry goods).
6. **Block cook time** — decide which meals to batch on which day. Add to calendar if helpful.

## Notes / Gotchas

- Overplanning is common. Five dinners is usually plenty — leave two nights flexible for leftovers or eating out.
- Check supermarket offers before finalising the plan, not after.
