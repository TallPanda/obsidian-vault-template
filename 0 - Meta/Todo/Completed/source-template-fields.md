# Source Template Fields

What fields does the source template need?

## Resolved

Decided on: `type`, `topic`, `medium`, `status` in frontmatter. `status` uses `active`/`done`.

`medium` covers: book, article, video, docs, podcast.

Promoted to spec: `2023-11-15-source-folder-structure-design.md` — which also settled the folder layout question that came up during this investigation.
